# 🚀 Angular 22 Full-Stack Application

**A modern Angular 22 web application with Server-Side Rendering (SSR), Leaflet maps, Chart.js analytics, and Express.js backend integration.**

![Angular](https://img.shields.io/badge/Angular-22-red.svg)
![TypeScript](https://img.shields.io/badge/TypeScript-Strict-blue.svg)
![Express](https://img.shields.io/badge/Express-5.x-green.svg)

---

## 📌 Features

- **Angular 22** with standalone components (default)
- **Server-Side Rendering (SSR)** using Express.js
- **Interactive Maps** powered by Leaflet
- **Data Visualization** using Chart.js
- **Toast Notifications** via ngx-toastr
- **Signal-based State Management** (Angular Signals)

---

## 🛠️ Tech Stack

- **Frontend:** Angular 22, TypeScript 6.0, RxJS
- **Backend:** Express 5.0, Node.js
- **Styling:** CSS3 (with Leaflet & Chart.js integration)
- **Testing:** Vitest
- **Build Tool:** Angular CLI 22
